# Day 16: Reverse a Number in Python

## 📌 Description
This Python program reverses the digits of a given positive integer using a `while` loop.

## 🎯 Objective
To understand how to extract digits and reverse a number using arithmetic operators.

## 💻 Concepts Used
- `input()` and `int()`
- `while` loop
- Modulus operator (`%`)
- Floor division operator (`//`)
- Arithmetic operations

## 🧠 How It Works
1. Get a number from the user.
2. Extract the last digit using `% 10`.
3. Add the digit to the reversed number.
4. Remove the last digit using `// 10`.
5. Repeat until the number becomes zero.
6. Print the reversed number.

## ▶️ Example Output
```text
Enter number: 12345
Reverse = 54321
```

I learned how to reverse a number using a `while` loop and arithmetic operators in Python.
